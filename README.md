# 『明鏡』実践！ファネル弱点診断

8問の質問に答えると、ビジネスのファネル（認知 → 興味 → 比較 → 購入）のどこに弱点があるかを診断するWebページです。

## 中身

- `index.html` 1ファイルだけで動きます（外部ライブラリ・サーバー・データベースは使っていません）。
- 回答内容はどこにも送信・保存されません。ページを閉じると消えます。

## 診断の流れ

1. スタート画面 → 「診断をスタートする」
2. 質問 8問（各4択：3点 / 2点 / 1点 / 0点）
   - Q1〜Q4：集客・育成力（認知・興味フェーズ）
   - Q5〜Q8：決定・販売力（比較・購入フェーズ）
3. 結果ページ
   - 合計点（24点満点）でランク表示：20点以上 S / 14点以上 A / 8点以上 B / それ未満 C
   - 前半・後半それぞれの達成率（%）と、100% / 60%以上 / それ未満 の3段階のコメント

## 動かし方

- パソコンで `index.html` をダブルクリックすると、ブラウザで開けます。
- 公開する場合は、`index.html` をそのまま GitHub Pages などの静的ホスティングに置けば動きます。

## 文章を直したいとき

- 質問文：`index.html` 内の `const questions = [` の部分
- 選択肢：`const optionsTemplate = [` の部分
- 結果コメント：`function showResult()` の中の `acqText = ...` / `salesText = ...` の部分
